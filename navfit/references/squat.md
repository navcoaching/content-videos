# Reference notes — squat

No YouTube reference was provided for this first prototype.

Content in `exercises/squat/content.yaml` is based on widely taught, general squat
technique (stance, hip hinge + knee bend, knees tracking toes, heels down, neutral spine,
balance over mid-foot). Items that depend on the individual or on coaching preference
are marked `needs_review` (stance width, toe angle, depth cue).

To attach a reference: `python -m navfit ref <youtube-url> --exercise squat`, then paste
the transcript or a summary into the generated file if it could not be fetched.
