# NavFit: إنتاج فيديوهات شرح التمارين (Nav Coaching)

خط إنتاج يولّد مقاطع قصيرة تشرح أداء التمرين بالشخصية نفسها في كل مقطع:
- شخصية رياضية ثلاثية الأبعاد بهودي سماوي يغطي الرأس، وبنطال كحلي.
- شعار Nav Coaching على الصدر، مأخوذ من ملفك الأصلي.
- تمويه للوجه في كل إطار.
- رسوم تشرح الحركة: أسهم، إبراز المفاصل، خطوط نطاق الحركة، مسار الورك، خط التوازن، والأخطاء الشائعة وتصحيحها.

## التشغيل السريع

```bash
pip install -r requirements.txt           # مرة واحدة
# لينكس بدون شاشة: apt-get install libegl1 libegl-mesa0 libgl1-mesa-dri
python -m navfit check squat              # ما يحتاج مراجعة المدرب قبل النشر
python -m navfit render squat             # حسب config.yaml
python -m navfit render squat --aspect both --quality final
python -m navfit render squat --quality draft --preview 3,12,30   # صور ثابتة سريعة للمراجعة
```

المخرجات في `output/<exercise>/<aspect>_<lang>/`:

| الملف | المحتوى |
|---|---|
| `*_sfx.mp4` | الفيديو مع مؤثرات صوتية خفيفة |
| `*_clean.mp4` | الفيديو بدون صوت، لتسجيل التعليق الصوتي عليه |
| `VOICEOVER.md` | نص التعليق الصوتي موقّتاً على كل مشهد |
| `REVIEW.md` | قائمة المعلومات التي تحتاج تأكيد المدرب، وتأكيد تطبيق تمويه الوجه على كل الإطارات |

## ما الذي تعدّله؟

| تريد تغيير | الملف |
|---|---|
| اسم التمرين، اللغة، المدة، نسبة الأبعاد، الجودة، رابط المرجع، الشعار | `exercises/<ex>/config.yaml` |
| النصوص وحالة مراجعة كل معلومة (عربي/إنجليزي) | `exercises/<ex>/content.yaml` |
| ترتيب المشاهد، الزوايا، التصوير البطيء، الرسوم | `exercises/<ex>/storyboard.yaml` |
| الألوان والخطوط وشكل الهوية | `brand/brand.yaml` |
| ألوان الشخصية، حجم الشعار على الصدر، قوة تمويه الوجه | `brand/character.yaml` |
| الإضاءة وزوايا الكاميرا | `brand/studio.yaml` |

- **اللغة:** اضبط `language: en` لتظهر النصوص الإنجليزية الموجودة في `content.yaml`.
- **نسبة الأبعاد:** `9:16` أو `16:9` أو `both`. في 16:9 تُزاح الشخصية لليسار وتُعرض النصوص في عمود على اليمين.
- **المدة:** `target_duration` يطوّل لقطات التجميد أو يقصّرها بحدود ±25–50%، ولا يغيّر سرعة الحركة.

## مبدأ الدقة
- كل نص على الشاشة موجود في `content.yaml` ومعه حالة `verified` أو `needs_review`، ومعه سبب اعتماده (`basis`).
- الأمر `check` وملف `REVIEW.md` يعرضان ما لم يُراجَع بعد. **لا تنشر قبل مراجعته.**
- الحركة ليست رسماً يدوياً: القدمان ثابتتان، والرجلان تُحسبان بالكينماتيكا العكسية (IK)، ومركز الثقل يُحسب في كل إطار ليبقى فوق منتصف القدم. زوايا الركبة والورك في أسفل الحركة تُطبع عند تشغيل `python -m navfit.motion`.
- الأخطاء الشائعة نسخ معدّلة من الحركة نفسها (`motion.py → STYLES`)، وليست لقطات منفصلة.

## مرجع يوتيوب
```bash
python -m navfit ref "https://www.youtube.com/watch?v=..." --exercise squat
```
- **يجلب:** العنوان والقناة (oEmbed)، ثم يحاول جلب التفريغ النصي والوصف.
- **يكتب:** `references/<exercise>-<id>.md`، ويسجّل فيه ما نجح وما تعذّر.
- **عند تعذّر التفريغ** (الشائع من الخوادم السحابية بسبب التحقق من الروبوت) يطلب منك لصق التفريغ أو ملخص، ولا يدّعي أنه حلّل الفيديو.
- المرجع يُستخدم لفهم التمرين فقط، ولا تُنسخ منه لقطات أو صوت أو نص حرفي.

## التصوير الحقيقي (المسار أ)
```bash
python -m navfit blur-video input.mp4 output.mp4 [--debug]
```
- **آلية التتبّع:** كشف الوجه من MediaPipe، ويكمله تتبّع نقاط الرأس من نموذج الوضعية عندما يكون الوجه جانبياً أو الحركة سريعة، مع تنعيم للحركة.
- **عند فقدان الوجه:** يبقى التمويه موسّعاً ولا يُكشف الوجه أبداً. وإذا لم يُعرف موقع الرأس بعد، يُموَّه الثلث العلوي من الإطار كله.
- **التقرير:** يُكتب في `output.mp4.privacy.json` ويذكر عدد الإطارات حسب مصدر التتبّع.

## الأدوات والتكاليف

| الأداة | الاستخدام | التكلفة |
|---|---|---|
| Blender (bpy 5.0) | بناء الشخصية والتصيير (Workbench) | مجاني ومفتوح المصدر |
| Mesa llvmpipe (EGL) | OpenGL بدون كرت شاشة | مجاني |
| ffmpeg، OpenCV، Pillow + libraqm | المونتاج والنص العربي | مجاني |
| MediaPipe | تتبّع الوجه للتصوير الحقيقي | مجاني (النماذج تُحمّل من Google) |
| خطوط Tajawal وMontserrat | النصوص | مجانية (رخصة OFL) |
| youtube-transcript-api | التفريغ النصي إن كان متاحاً | مجاني، وقد يُحجب من الخوادم |

**لا توجد أي خدمة مدفوعة في النسخة الحالية.**

خيارات مدفوعة لاحقاً إن أردت واقعية أعلى، مع التنبيه أنها ليست مفعّلة ولم تُختبر:
- **مولّدات الفيديو بالذكاء الاصطناعي** (Runway، Kling، Veo): تُسعَّر بالثانية أو بالاشتراك. تحقق من الأسعار الحالية في مواقعها الرسمية قبل الاعتماد عليها. نقطة ضعفها المعروفة: تشويه الشعارات وعدم دقة حركة المفاصل.
- **شخصية واقعية ثلاثية الأبعاد:** مثل Character Creator أو MetaHuman، مع التقاط حركة حقيقي. هذه الأدوات تتطلب تراخيص وجهاز بكرت شاشة.

## الأداء (في بيئة التطوير: 4 أنوية، بدون كرت شاشة)
- **تصيير الإطار ثلاثي الأبعاد:** ~0.8 ثانية بدقة 540×960، و~1.3 ثانية بدقة 1080×1920.
- **فيديو كامل مدته ~50 ثانية بدقة 1080p:** 25–35 دقيقة للتصيير الأول. الإطارات تُحفظ في `output/cache`، فإعادة المونتاج بعد تعديل النصوص تستغرق دقائق.

## إضافة تمرين جديد
1. أضف مولّد حركة في `navfit/motion.py` وسجّله في `MOTIONS`، مثل `Lunge` أو `PushUp`. تمارين الأجهزة تحتاج أيضاً نموذج الجهاز في `scene3d.py`.
2. انسخ `exercises/squat` وعدّل `config.yaml` و`content.yaml` و`storyboard.yaml`.
3. شغّل `check` ثم `render --quality draft --preview ...` ثم `render`.

## هيكل المشروع
```
navfit/
  brand/            الهوية، الشعار، الخطوط، الشخصية، الاستوديو
  exercises/squat/  الإعدادات، المحتوى مع حالة المراجعة، المشاهد
  navfit/
    motion.py       نموذج الجسم وكينماتيكا التمارين وأخطاؤها
    scene3d.py      الشخصية والاستوديو والكاميرات في Blender، والتصيير
    compose.py      التخطيط، الرسوم، تمويه الوجه، الانتقالات، الصوت
    graphics.py     أدوات الرسم والنص العربي
    reference.py    استخراج معلومات مرجع يوتيوب
    privacy_video.py تمويه الوجه للتصوير الحقيقي
  references/       تقارير المراجع
  output/           المخرجات والكاش (غير مرفوعة إلى git)
```
